# 02｜零基础分步开发与提示词

每个阶段都执行“交给 AI → 等它实现 → 自己点一遍 → 保存检查点”。不要一次发送全部阶段。遇到错误先使用文末修复提示词；不能靠删除功能让报错消失。

## 1. 软件准备与第一次运行

### 1.1 你需要准备什么

| 软件 | 程序阶段用途 | 安装要求 |
|---|---|---|
| Godot 4.5.2 标准版 | 运行、编辑、导出游戏 | Windows 64 位标准版；不选 .NET；解压到固定目录 |
| 同版本 Export Templates | 导出 Web/Windows | Godot 编辑器内安装，版本必须与编辑器一致 |
| 浏览器 | 测试 Web | 首先用实际教室电脑上的 Chrome 或 Edge，再补测其他目标浏览器 |
| 可读写项目文件的 AI 助手 | 按本套提示词生成完整工程 | 使用现有工具即可；不是只接受聊天里零散代码 |
| Git（建议） | 每阶段可恢复检查点 | 可由 AI 检查是否已安装；暂时不会用可先复制完整源文件备份 |
| Python（可选） | AI 生成本地预览启动工具时使用 | 已有环境则复用；不是运行游戏的必要条件 |
| Blender（美术阶段） | 制作低模模型与 GLB | 程序占位阶段不需要；美术成员自行固定版本 |

Godot 下载：[4.5.2 官方归档](https://godotengine.org/download/archive/4.5.2-stable/)。下载标准版并解压；双击编辑器主程序。若显示未知发布者提示，先核对来源，不从非官方镜像随意安装。

首次可由 AI 创建 `game/project.godot`。随后在 Godot 项目管理器点“导入”，选该文件，打开工程。右上渲染方式应为 Compatibility；第一次导入等资源扫描完成。F6 是运行当前场景，F5 是运行整个项目，日常验收用 F5。首次 F5 如询问主场景，选择 AI 创建的 `scenes/app/Boot.tscn`。

导出模板一般在“编辑器 → 管理导出模板”安装 4.5.2；界面语言不同可搜索 Export Template Manager。然后“项目 → 导出 → 添加 → Web”，关闭 Thread Support。主文件名使用 `index.html`，整组导出文件必须保留。关于单线程、Compatibility 与浏览器限制，以 [Godot 4.5 Web 官方文档](https://docs.godotengine.org/en/4.5/tutorials/export/exporting_for_web.html) 为准。

### 1.2 检查点怎么保存

让 AI 检查现有版本管理，避免覆盖他人修改。每阶段验收通过后提交源文件、关卡、测试和文档，检查点命名如 `S03-rules-pass`。不要提交 `.godot/` 导入缓存。若没有 Git，则先停止编辑器写入，用文件管理器把 `game/` 源文件复制到同级带阶段号的备份目录，排除可再生成缓存和大型导出文件；不能只备份脚本而漏掉场景/配置。

## 3. 分步开发清单

### S00｜环境检查与空工程 Web 验证

前置：只有资料也可开始。本阶段只创建最小运行入口，不开发完整玩法。

```text
执行 S00。检查工作区、已有文件、Godot及导出模板版本。创建 game/ 的最小 Godot 4.5.2 Compatibility 工程，一个显示中文标题和“开始测试”的原生按钮，点击后数字+1。记录实际 Godot 可执行文件路径；缺少软件时给我准确官方下载页和逐步安装方法。配置单线程 Web 预设，实际导出并通过本地 HTTP 服务验证按钮、中文和刷新；提供双击或清楚的一步预览入口，不要求双击 HTML。完成 ENVIRONMENT.md，明确哪些环境验证已实际完成。
```

你来验收：F5 后看到中文，连续点击 3 次数字为 3；按 AI 的预览说明在浏览器重复操作。不能只在编辑器成功。失败先解决环境，暂不加玩法。

### S01｜工程骨架、页面导航与设置

前置：S00 通过。

```text
执行 S01。按01的目录与模块边界搭建Boot、首页、关卡地图、牧场、小镇、设置和弹窗宿主。使用统一 SessionController 保留跨页面数据。先用占位页面打通首页→第1关→小镇→牧场→地图→首页；无存档时禁用继续，未解锁关卡禁用。建立音乐/音效/减弱动效设置、统一输入遮挡和中文字体入口。此时夜晚等未实现按钮应明确禁用说明，不能假装通关。提供导航冒烟测试和操作说明。
```

你来验收：每个可用入口有返回方式；开设置后点击背后位置不触发选地；窗口缩小时主要按钮仍能点到。此阶段的临时禁用项记录在进度表，S14 前必须消除正式流程缺项。

### S02｜关卡数据与固定相机场景

前置：S01。先完成 S02a 再 S02b。

```text
执行 S02a。实现 LevelDefinition 导入、schema校验和前两关数据，读取04及data/levels_document_examples.json，但不要信任输入而跳过校验。校验行列数、地形字符、唯一羊ID、羊在陆地、外圈狼入口、阈值及预算。前两关地形中的S等价于g加羊。建立坐标往返测试，并输出可读的校验错误，不用默认值悄悄修坏图。
```

```text
执行 S02b。建立 Ranch 场景，正方形逻辑格映射到XZ平面，固定正交斜俯相机；用简单低模方块/几何体搭建陆地、功能牧草、水、山石、羊占位与地图外狼行动带。所有模型挂在VisualRoot可替换；独立GridPicker映射鼠标/触摸到格坐标，不能依赖美术碰撞体。地图中央、UI沿边缘；显示测试坐标开关。大图自动适配可见区域，不旋转镜头。
```

你来验收：第一关 6×5、两羊在 (3,3)(4,3)，第二关 8×6、水在 (6,3)，不能把水画成可用地。检查四角格点击位置正确；换窗口尺寸再次检查。

### S03｜不依赖画面的圈地规则

前置：S02a。做完纯规则再绑定 UI。

```text
执行 S03。实现无场景依赖的 Planner、组件排序、唯一边ID、A/P/W/F、羊归属和自然资源统计，规则严格按01第4～5节。加 tests/run_all.gd，可在无窗口模式运行且失败退出码非零。必须覆盖单格、2×2、相邻、斜角、孔洞、地图边、山石、水岸、多牧场和两关参考解。输出分析对象并让测试结果给出实际值/期望值，不允许修改期望数值迎合错误实现。
```

你来验收：让 AI 展示 2×2 得 A4/P8/W0/F8；第二关横向方案得 A8/P12/W1/F11。规则没过不进入 S04。

### S04｜规划交互与围栏预览

前置：S02b、S03。

```text
执行 S04。接入添加/擦除、点击拖动、快速笔划格遍历、按笔划撤销/重做、禁选反馈、取消草稿恢复、规划卡实时数字。使用同一份PlanAnalysis边界数据生成预览围栏，包含孔洞、地图边、柱角去重；不可把水岸画成实付栅栏。草稿不动账。处理UI遮挡、鼠标出界、失焦、触摸与鼠标重复事件。暂时确认只走待接账务接口，不伪造扣款。
```

你来验收：拖选四格、撤销一次全部撤回、重做恢复；点水不选中；开弹窗操作不改变背后格；取消回到已建方案。快速拖动和慢速拖动结果一致。

### S05｜账本、建造、供给与退款

前置：S04。分三步执行。

```text
执行 S05a。实现整数账本、规则价格快照、建造完整方案差额事务、command_id幂等和状态版本校验；预览与确认共用分析结果。余额不足必须保持旧格集、旧围栏、旧余额全部不变。先实现可测试内存事务，再给后续持久化留出明确提交接口。测试改建退款、空集拆除、取消不扣款和重复确认。
```

```text
执行 S05b。实现草份/水桶采购批次，按实付批次退款，水仅完整未消费桶可退，最新批次优先。实现购买库存与自然供给分离、组件顺序自动预分配、FIFO批次预占、退款后重分配。不能在规划预览中消费库存。测试总缺水5需买2桶、原价/折扣混合批次、超量退款拒绝、防折扣套利。
```

```text

```

你来验收：第一关四格围栏扣 8，余额 8；买一桶水扣 4，余额 4，库存水 4 份，预分配 2；退桶后余额 8、水 0、缺水 2。重复点击确认不重复扣。

### S06｜小镇、商店、页面闭环

前置：S05。


你来验收：未提交草稿时去商店买水，再回牧场，草稿和余额正确；买不起的数量无法购买；买 0、负数或超量输入被服务拒绝；关掉商店不重置预算。

## 6. 导出与测试操作补充

优先让 AI 根据记录的真实可执行路径生成 `tools/run_tests.ps1` 与 `tools/preview_web.ps1`；脚本路径和报错必须中文说明。不要要求零基础用户自行拼凑引号或修改系统安全策略。

AI 可采用以下命令形态，但必须替换为实机路径、实际运行并检查退出码：

```powershell
# 以下路径为示例，不能照抄当作已安装路径。
& 'C:/Tools/Godot/Godot_v4.5.2-stable_win64.exe' --headless --path 'D:/Projects/GoodNight Baa/game' --editor --import
& 'C:/Tools/Godot/Godot_v4.5.2-stable_win64.exe' --headless --path 'D:/Projects/GoodNight Baa/game' --script res://tests/run_all.gd
& 'C:/Tools/Godot/Godot_v4.5.2-stable_win64.exe' --headless --path 'D:/Projects/GoodNight Baa/game' --export-release Web builds/web/index.html
```

本地网页需 HTTP 服务。可以用已安装 Python 在 `builds/web` 中启动 `python -m http.server 8060 --bind 127.0.0.1`，再访问 `http://127.0.0.1:8060/`；首次由 AI 根据现有环境给出可直接运行的方式，端口冲突就明确更换并记录。窗口关闭服务会停止。不要直接双击 `index.html`，不要单独移动 HTML 而丢掉 `.wasm`、`.pck` 等同组文件。

导出只代表生成了包；必须实际打开页面并操作。首次点击“开始”时解锁音频；页面无声应分别检查浏览器策略、静音设置、资源槽位，不将缺音频误判为规则失败。
