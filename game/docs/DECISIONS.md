# 开发决策

2026-09-17，阶段 S00。

| 决策 | 依据与影响 |
|---|---|
| Godot 4.5.2 标准版、GDScript、Compatibility | 按 01/02 固定基线，已复用本机版本，不自动升级 |
| 仅最小 Control 场景 | S00 明确只要求中文按钮；3D 正交牧场属于 S02，本阶段不提前实现，也未改动后续 2.5D 技术路线 |
| 中文字体随包 | Noto Sans CJK SC Regular，SIL OFL 1.1；不依赖系统字体 |
| 文案通过 TextCatalog.format | 当前仅 S00 文案与 count 变量；完整文案验证器、素材清单仍属于后续阶段，未宣称完成 |
| Web 使用项目内 nothreads 模板 | 全局模板目录无可用 4.5.2 模板；从官方整包取单线程 debug/release，两项自定义路径均明确配置 |
| 计数刷新归零 | 环境测试不保存进度；正式存档属于 S08 |
| 本地预览固定 127.0.0.1:8060 | 只绑定回环地址；无公网部署；只服务 builds/web，原策划不随包发布 |
| 字体先保留完整字库 | 避免后续改文案缺字；S00 包体约 52.9 MB，尚未做性能优化承诺 |
| 无 Git 初始化或已验收提交 | 初始目录无 .git，当前提供 S00 源码候选备份；用户人工验收前不命名为 pass |
| 原稿两关与候选六关区别保持 | 本阶段不导入关卡；样本导入和程序核验留待 S02/S12，不能用文档核验代替游戏测试 |

01 文档的账务、退款、PK、狼、存档默认值将在相应阶段实施并补记，本次尚未实现这些系统。


## 2026-09-18 / S01

- 用户明确要求继续 S01，保留 S00 未完成人工验收的真实记录。
- Boot 作为常驻壳，持有 SessionController、AudioService；主页面使用独立场景，渲染控件通过 UI 工厂与共用 page.gd 复用；不把全部节点设为 autoload。
- application/session_controller.gd 管状态、页面准入及设置；presentation 管控件、视图、音频与占位反馈。domain、关卡数据目录暂留空，不提前开发 S02。
- 牧场与小镇用 SubViewport 中的固定正交3D占位模型，VisualRoot可替换；本阶段不是正式关卡地图和选择命中实现。
- 本次内存会话不等于存档：continue始终禁用，另有“返回本次牧场”；关闭/刷新清除本次互动，设置单独存user://settings_v1.cfg。正式双槽游戏存档仍在S08。
- 音乐、SFX分总线，初值遵循01；当前试听为程序生成短音，不冒充正式声音。减弱动效取消占位跳动，保留计数。
- 弹窗同时阻挡GUI输入、禁用背景焦点、拒绝后台会话命令；Esc关闭后恢复焦点。关闭入口固定顶部，内容可滚动。
- 不提交虚假成绩/解锁，不显示虚假账本或安全判定；3～8关候选身份保留。
- 保存设置使用ConfigFile、版本与类型检查；简单设置文件与未来事务存档分离，写入失败显示提示。未承诺云同步和所有浏览器永久持久化。
