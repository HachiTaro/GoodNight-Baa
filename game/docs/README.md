# S01 运行与验收

现在 F5 打开的是首页。S00 原测试页保留在 scenes/app/S00Probe.tscn，旧说明见 README_S00.md。

## 打开游戏

1. 在文件管理器打开 D:\Projects\GoodNight Baa\game。
2. 本机运行：双击 open_editor.cmd，等待扫描结束，按 F5。
3. 网页运行：双击 preview_web.cmd，保持服务窗口开启；打开 http://127.0.0.1:8060/。不要双击 HTML。如果已有此项目预览服务，可直接打开网址。页面仍是旧版时刷新一次。
4. 若有启动错误，把窗口里的第一条错误发给 AI；版本和环境路径仍见 ENVIRONMENT.md。不要安装新插件或升级 Godot。

## 按顺序点击验收（约 3 分钟）

1. 首页检查：能看到“开始游戏”“关卡地图”“设置”；“继续游戏”灰色，并说明暂无可用游戏存档。
2. 开始游戏：进入第 1 关占位牧场，显示两只方块羊。点击“摸摸小羊”两次，次数为 2。
3. 前往小镇：看到占位商店，“商店（尚未开放）”灰色。点“返回牧场”，摸羊次数仍为 2。
4. 点“关卡地图”：第 1 关可进入；第 2～8 关灰色并显示前置条件；第 3～8 关标注“候选关卡”。顶部“返回首页”可用。
5. 返回首页后点“返回本次牧场”，次数仍为 2。该按钮只恢复本次打开期间的内存数据，不是正式“继续游戏”。
6. 打开设置：调整总音量、音乐和音效滑条，点对应“试听”按钮。这里只是短测试音，没有正式音乐、羊叫或自动循环音乐。总音量 0 应完全静音。
7. 打开“减弱动效”，关闭设置后摸羊：次数增长但羊不跳。关掉减弱动效后再次摸羊，应短暂轻跳。
8. 弹窗遮挡：打开设置后点弹窗外的暗色背景，不应触发背后的按钮；按 Tab 只能在弹窗内切换焦点。按 Esc 或顶部“关闭设置”可返回原页面。
9. 设置内“返回首页”在可滚动内容底部；滚动不会丢掉顶部关闭按钮。
10. 返回首页点“开始游戏”：已有本次牧场时应询问是否重开。取消保留次数；确认重开次数为 0，音量和减弱动效保持。
11. 调整窗口为约 960×540，检查牧场导航和设置关闭按钮仍可操作；地图和设置内容可滚动。
12. 关闭重开或刷新后，设置应保留；本次牧场结束、继续按钮仍灰色。这是 S01 的预期范围，正式玩法存档在 S08。

原生程序和浏览器分别保存设置，不互相同步。网页需保持相同网址和端口；隐私模式或清除站点数据可能清掉设置。

## 测试和重新导出

- 双击 run_tests.cmd：执行实际 Godot 导入与 49 项导航/状态/设置断言（包含 S00 回归和按钮可用性断言）。正常结果是 S01 RESULT checks=49 failed=0；详见 docs/test-s01.log。
- 双击 export_web.cmd：重新生成 builds/web 的完整网页包。修改源文件后要重新导出，浏览器才会更新。
- tests/capture_layout.gd 是开发用图形布局截图入口；不是主场景，不需要普通用户运行。
