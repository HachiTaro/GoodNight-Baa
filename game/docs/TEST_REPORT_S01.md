## 修复与测试边界

1. 首次自动窗口宽度断言错误地把逻辑坐标与物理窗口宽度比较；Godot canvas_items 下 960×540 仍对应 1280×720 逻辑画布。改用可见逻辑画布边界，并新增实际 960×540 图形截图核对。不是改期望值掩盖布局错误。
2. 设置关闭按钮初版位于滚动内容末尾；实际网页检查发现不够方便，已移至固定顶部，再执行全部 49 项回归并重新导出。
3. 应用内浏览器工具强制覆盖成 960×540 时，画布缩在左上且坐标点击不能可靠验证；恢复默认尺寸后显示正常。尚不能确定这是浏览器覆盖机制还是网页缩放兼容问题，因此该网页缩放项记待测，不标通过。原生 960×540 渲染正常。
